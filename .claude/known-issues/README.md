# 알려진 이슈

우리 코드만으로 해결할 수 없는 문제(백엔드 API 미확정·불일치, Figma 자산 누락, 브라우저 호환성, 외부 서비스)를 기록한다.

- 일시적인 로컬 오류, sandbox 제약, 한 번의 명령 실패, 같은 변경에서 고칠 수 있는 문제는 기록하지 않는다.
- 기록 전에 재현 가능한 증상, 사용자·개발 흐름에 주는 영향, 코드만으로 못 고치는 근거가 모두 있는지 확인한다.
- 새 이슈는 `records/short-title.md`로 쓰고 `template.md`를 따른다.
- 상태는 `open`, `monitoring`, `resolved`, `wontfix` 중 하나다. 외부 조치가 필요하면 담당 주체와 다음 확인 시점을 남긴다.
- 흔한 예: Swagger와 실제 응답이 다름(HTTP 200인데 본문 code가 에러 등) — curl 재현 명령, 확인 날짜, 백엔드 담당 확인 요청을 함께 남긴다. Figma 값에 맞는 토큰이 없음 — 하드코딩하지 않고 가장 가까운 토큰으로 근사한 뒤 원래 값과 근사 토큰을 표로 남기고 토큰 추가를 요청한다.
- 해결한 이슈는 지우지 않고 상태와 해결일을 갱신한다. 비슷한 이슈는 새로 만들기 전에 기존 기록을 먼저 확인한다.
