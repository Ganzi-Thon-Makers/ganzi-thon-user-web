# API 계약 기록

백엔드 명세에서 확인한 계약을 도메인별로 남긴다. 구현은 이 기록을 근거로 하고, 새 엔드포인트를 확인하면 같은 변경에서 갱신한다.

- 명세 출처: 백엔드 Swagger (주소는 `NEXT_PUBLIC_API_URL` 기준. 문서에 주소 값을 직접 쓰지 않는다)
- 관련 파일만 읽는다. 모든 도메인 문서를 한꺼번에 읽지 않는다.

| 도메인 | 파일       |
| ------ | ---------- |
| stamp  | `stamp.md` |

## 도메인 파일 형식 (`<도메인>.md`)

```md
# <도메인> API

한 줄 용도. 명세 확인일: YYYY-MM-DD

## Endpoints

| Method | Path | Operation | 비고 |
| ------ | ---- | --------- | ---- |

## <스키마 이름>

| Field | Type | 비고 |
| ----- | ---- | ---- |

## 구현 메모

- 인증 필요 여부, 권한 판별, 서버 필드명과 도메인 이름이 다른 곳
- 아직 확인 안 된 스키마·에러 응답
```

## 확인 필요 항목

- 공통 응답 envelope 형태
- 에러 응답 형태 (`shared/api/error.ts`의 `ErrorBody`와 맞는지)
